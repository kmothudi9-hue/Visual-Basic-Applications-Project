# Car-Service Booking System | Excel VBA

An academic Excel project that models a simple vehicle-service workflow using VBA UserForms. It captures bookings and selected parts, then records service details, discounts and totals in a workbook.

## Project overview

The project brings a booking form and a service form together in one macro-enabled Excel workbook. It was developed as an academic assignment and later refined as a portfolio project. The focus is on practical spreadsheet automation, structured data capture and event-driven programming.

## Features

- Capture customer details and vehicle registrations through a booking form.
- Select replacement parts, including oil, spark plugs, air filters and tires.
- Record booking information on the **Make Booking** worksheet.
- Select a registration when recording a completed service.
- Enter a service price and discount and display a calculated total.
- Save service details on the **Service Done** worksheet.
- Use VBA form events and basic validation to support the workflow.

## Tools and concepts

- Microsoft Excel for Windows
- Visual Basic for Applications (VBA)
- UserForms, form controls and event handlers
- Worksheet interaction and structured data entry
- Input validation and percentage calculations

## How to use

1. Open a copy of the macro-enabled workbook (`.xlsm`) in desktop Microsoft Excel for Windows.
2. Review the workbook and enable macros only if you trust its source. VBA macros can run code on your computer.
3. Use the booking form to enter a booking and select any relevant parts.
4. Open the service form, select a registration, and enter the service price and discount.
5. Save the service record and review the corresponding worksheet.

Excel for the web does not run VBA UserForms. Use fictional data when demonstrating or testing the workbook.

## Development and testing

The original workbook was working before the later modifications. The updated code has been worked on in desktop Excel, and further checks are recommended before relying on or sharing it. Useful scenarios include bookings beyond the initial rows, blank or missing entries, changing the price after setting a discount, and confirming saved totals and splash-screen behaviour.

This is a learning project, not a production system or a payment processor. It should not be used to store real customer data without further privacy, security and reliability work.

## Portfolio context

This project demonstrates Excel automation and structured data capture rather than a reporting dashboard. It forms part of my learning journey in Excel, VBA and practical problem-solving.
